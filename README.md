## 📊 功能介绍

### 数据抓取
- **抓取全部**：一次抓取近 3 天所有平仓数据（最多 500 条）
- **强制刷新**：忽略缓存，重新从服务器拉取
- **自动刷新**：可设置 1/3/5/10 分钟自动刷新
- 支持合并模式 / 仅建仓提醒 / 仅平仓提醒 三种视图

### 筛选与搜索
- 按日期范围筛选
- 按老师筛选
- 按方向筛选（多/空）
- 按品种名称搜索（如"美黄金"）

### 数据编辑
- 点击点位/盈亏数字可直接修改
- 修改后自动重新计算金额
- 显示 ✏️ 编辑按钮和 "已改" 标签

### 导出
- **导出 CSV**：GBK 编码，兼容 Excel
- **导出 Excel**：带颜色高亮的电子表格格式
- 快捷键 `Ctrl + E` 快速导出

### 老师盈亏汇总
- 底部展示各老师喊单统计
- 显示：总喊单数、盈利/亏损笔数、胜率、盈亏比、总盈亏金额
- 按总盈亏排序，支持盈亏比参考

### 数据可视化
- 点击 **📊 数据图表** 展开可视化面板
- **饼图**：各老师盈亏金额占比
- **趋势图**：每日盈亏变化折线

| 快捷键 | 功能 |

## 📋 字段说明

| 字段 | 说明 |
|------|------|
| 开仓时间 | 老师喊单建仓时间 |
| 方向 | 多（做多）/ 空（做空） |
| 商品 | 品种名称 |
| 开仓点位 | 建仓价格 |

| 平仓点位 | 实际平仓价格 |

## 🔧 常见问题

**Q: 解锁密码忘了？**
> 默认密码是 `135917`，如有变更请联系作者。

**Q: 数据抓不到/显示"连接失败"？**
> 检查网络是否正常，确认大粤K线服务器 `fu.yemacaijing.net` 可访问。

**Q: 盈亏金额显示"未知品种"？**
> 该品种尚未配置汇率换算，可手动修改盈亏金额。

**Q: 安装包下载后无法运行？**
> 请关闭杀毒软件后重新下载安装。

**Q: 如何更新到新版本？**
> 新版本发布后，打开软件会提示"发现新版本"，点击"安装更新并重启"即可。
